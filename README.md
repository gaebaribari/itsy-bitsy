# 루틴 앱 [잘게잘게]

'잘게잘게'는 추상적인 목표를 메모장에 적듯 가볍게 작은 할일로 나누고, <br/>
버튼을 눌러 하나씩 성취감을 쌓아가는 앱입니다. 

홈페이지 👉 https://apps.apple.com/kr/app/잘게잘게/id6503808613 (현재는 사용자가 없어 중단)

## 개발환경

`Dart (Flutter)`, `Firebase`

## 주요성과

1. **애니메이션 효과 및 UI 향상**
  앱의 재미와 사용자 경험을 높이기 위해 다양한 스택과 애니메이션 효과를 사용하였습니다.

2. **Provider를 사용한 상태 관리**
  Provider 패턴을 활용하여 전역 데이터 구조를 설계하고, 이를 기반으로 앱 전반에 걸쳐 데이터를 관리하였습니다.

3. **사용자 데이터 입력 Form 구현**
  사용자로부터 데이터를 입력받기 위해 다양한 Form을 구현하였으며, 유효성 검사 및 입력 필드의 사용자 친화적인 디자인을 고려하였습니다.

4. **UI 디자인 (Figma)**
  Figma를 사용하여 직관적이고 사용하기 쉬운 인터페이스를 목표로 앱의 UI를 디자인하였습니다.

5. **사용성 향상**
  `GestureDetector`와 `ElevatedButton`을 적절하게 사용하여 사용자 경험을 개선하였습니다.

6. **Navigation을 통한 화면 전환 및 데이터 전달**
  `Navigation` 기능을 사용하여 자연스러운 사용자 흐름을 유지하며, 화면 간 데이터 전달을 구현하였습니다.

7. **Snackbar를 사용한 알림 기능**
  `Snackbar`를 사용하여 사용자에게 피드백을 즉각적으로 제공하는 기능을 구현하였습니다.

8. **플러그인 및 외부 패키지 통합**
  `pub.dev`와 같은 패키지 저장소를 사용하여, 프로젝트에 필요한 외부 패키지를 검색하고 통합하는 경험을 하였습니다
